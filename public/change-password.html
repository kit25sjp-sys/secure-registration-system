🛡 Password Security

🔒
Bcrypt Hashing

Your password is hashed with bcrypt (cost 12) before storage. The plain-text password is never saved.

🚫
No Password Reuse

You cannot reuse any of your last 5 passwords. This prevents credential cycling attacks.

🔐
Strong Password Policy

Passwords must contain uppercase, lowercase, numbers, and special characters to resist brute-force.

👁
Admin Cannot See It

Even administrators cannot view your password — only a one-way bcrypt hash is stored in the database.
